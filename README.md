# Harfio site (yayımlanmadı)

GitHub Pages için hazır klasör; `mergeline-web` deseniyle aynı (Jekyll, `jekyll-theme-cayman`, main dalı kök). Sayfalar nihai metin (15 Eylül 2026): `index.md` destek, `gizlilik.md`/`privacy.md` gizlilik, `kullanim-sartlari.md`/`terms.md` şartlar. Yer tutucu kalmadı; `docs/legal/` taslakları artık tarihsel referans, canlı metin bu klasördür.

Yayın adımı (sahip onayı sonrası): `gh repo create harfio-site --public --source=site --push` → Settings → Pages → main / root. Adresler:
`https://tolgasayan2.github.io/harfio-site/` (destek), `/gizlilik`, `/privacy`, `/kullanim-sartlari`, `/terms`. Yayından sonra ASC gizlilik ve destek URL alanları ile paywall'daki Şartlar/Gizlilik bağlantıları bu adreslerle doldurulur.
